# Démonstration locale — S1

Utiliser une fenêtre de navigateur propre à partir de la racine `/`. Aucun compte ni remise à zéro de stockage nécessaire. Le serveur de présentation est démarré avec `pnpm build` puis `pnpm start --hostname 127.0.0.1 --port 3012`.

1. À l’accueil, identifier Optic 2000 Tahiti, choisir Baby Beach puis Glory Glory dans le nuancier. L’image, le prix et le lien suivent le modèle.
2. Ouvrir toutes les solaires. Rechercher **Glory**, puis cumuler collection Femme, coloris Cannelle transparente et budget 30 000–40 000 XPF. Appliquer, puis copier l’URL dans un autre onglet.
3. Ouvrir Glory Glory. Parcourir ses cinq coloris : 34 600 XPF pour les quatre premiers, 38 100 XPF pour Noir brillant Manchester United. Vérifier la photo et les vues de chaque choix.
4. Revenir aux résultats filtrés, puis utiliser le retour navigateur. Le contexte reste dans l’URL. Effacer les filtres. Rechercher **zzzintrouvable**, puis rétablir tous les modèles.
5. Ouvrir Maui Jim depuis les marques ; sa collection est accessible. Ouvrir Ray-Ban : présentation et trois magasins, sans faux produits.
6. Depuis un coloris, choisir « Se renseigner en magasin », puis Taravao. La sélection accompagne la visite et les horaires sont à confirmer. Inspecter les liens de téléphone, e-mail et plan sans les activer pendant la recette.
7. Sur téléphone, ouvrir le menu, le fermer avec Escape, vérifier le retour de focus et ouvrir les filtres. Baby Beach et son coloris « Argenté verre bleu hawaii » servent de second exemple.

Le catalogue général contient les 83 références. Le parcours détaillé des corrections de lentilles et le formulaire de contact appartiennent à S2. La version S1 n’est pas publiée et n’est pas remise au client final.
