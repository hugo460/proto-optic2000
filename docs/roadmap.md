# Roadmap

## S1 — lot local

Accueil et nuancier de trois modèles ; marques/gammes complètes ; recherche, filtres, tri, URL et aucun résultat ; catalogue 83/83, parcours solaire 78 modèles ; variantes solaires et galeries ; trois magasins et leur contexte de sélection. Sources, outils de contrôle, documentation et Git local.

Les cinq lentilles ont une fiche factuelle et un accès magasin. Les 33 variantes de lentilles, corrections et options ouvertes sont dans le modèle ; aucun sélecteur de correction n’est présenté comme terminé.

## S2 — après acceptation de S1 par le pilote

- Couvrir vue, lentilles/entretien, observation, basse vision, prothèses, services/garanties, équipe et contenus légaux à valider.
- Réaliser la sélection précise des lentilles avec signes, défauts et sphères ouvertes ; ne pas multiplier artificiellement les variantes.
- Contact/préparation de visite : formulaire local explicite de simulation, validation et reprise, sans envoi ni réservation effective.
- Exploiter les contenus publics utiles, traiter les anciens chemins et les offres datées sans les promouvoir comme actuelles.
- Conserver le monde visuel et la fidélité des données ; faire vérifier les informations commerciales et Taravao.

## S3 — après acceptation de S2

Recette de l’ensemble ; guide de démonstration complet ; revue finale du diff ; push GitHub ; publication Vercel au bon projet/SHA ; accès sans compte vérifié ; transmission du lien vérifié à Omar. Ces actions ne sont pas effectuées en S1.

La migration CMS/Kauehi, le domaine client, les comptes historiques, les ordonnances, le paiement et les stocks synchronisés ne sont pas construits dans ce prototype.
